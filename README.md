## Arcade Vault

It's a platform for playing online and competing for the highest score.

## Uses Spec-Driven Design

Based on /spec and /spec-impl

Following the best practices recommended here:

https://github.com/Klerith/fernando-skills

## Skills Used

```bash
npx skills@latest add Klerith/fernando-skills
```

## Commands

```bash
npm run dev      # start dev server (Next.js 16, Turbopack by default)
npm run build    # production build
npm run start    # run production build
npm run lint     # eslint via eslint-config-next
```
